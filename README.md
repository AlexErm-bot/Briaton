# Briaton — каталог интернет-магазина светильников

Интернет-магазин светильников **Briaton**: страница каталога с полным
функционалом выбора и покупки товаров. Реализован на чистом JavaScript
(vanilla JS) без фреймворков и сборщиков — на готовой HTML-разметке и CSS.

## Демо

Статический проект: откройте `catalog.html` в браузере.

## Возможности

- Бургер-меню каталога
  - открытие/закрытие выпадающего списка категорий
- Выбор города
  - дропдаун с выбором локации
  - выбранный город подставляется в шапку
- Динамические карточки товаров
  - отрисовка из `data/data.json` через `fetch`
- Фильтрация
  - по типу светильника
  - по наличию на складе
  - подсчёт количества товаров рядом с каждым чекбоксом
- Сортировка
  - по цене (дорогие/дешёвые)
  - по популярности (рейтинг)
- Корзина
  - добавление и удаление товаров
  - счётчик товаров
  - пустое состояние
  - выпадающее меню
- Аккордеон
  - блок «Ответы на частые вопросы»
  - открыт только один пункт
- Слайдер «Товары дня»
  - Swiper.js
  - только товары с `goodsOfDay: true`
- Валидация формы
  - Just Validate
  - имя 3–20 символов
  - email
  - чекбокс согласия
- Отправка формы
  - POST на `https://httpbin.org/post`
  - модальные окна успеха/ошибки
- Пагинация
  - по 6 карточек на страницу
  - `slice()` для выборки
- Тултипы
  - Tippy.js
  - наличие товара по городам на карточке

## Структура проекта

- `catalog.html` — страница каталога
- `css/`
  - `style.css` — скомпилированные стили
- `data/`
  - `data.json` — данные товаров (имитация сервера)
- `fonts/` — шрифты
- `images/` — изображения и спрайты
- `js/`
  - `main.js` — точка входа, подключение модулей
  - `components/` — независимые модули (меню, корзина, слайдер, форма…)
- `scss/` — исходные стили
- `vendor/` — внешние библиотеки

## Запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <https://github.com/AlexErm-bot/Briaton/>
2. Перейдите в папку проекта:
   ```bash
   cd Briaton
3. Откройте `catalog.html` в любом браузере. (для корректной работы fetch-запросов лучше использовать Live Server в VS Code или npx serve)

## Реализованный функционал

- Бургер-меню каталога — открытие и закрытие списка категорий
- Выбор города — дропдаун с подстановкой выбранного города в шапку
- Динамическая отрисовка карточек — загрузка данных из `data.json` через `fetch`
- Счётчики у фильтров — количество товаров в каждой категории
- Фильтрация — по типу светильника и наличию на складе
- Сортировка — по цене (возрастание/убывание) и популярности
- Корзина — добавление, удаление, счётчик и пустое состояние
- Аккордеон — блок «Ответы на частые вопросы», открыт один пункт
- Слайдер «Товары дня» — Swiper.js, товары с `goodsOfDay: true`
- Валидация формы — Just Validate (имя, email, чекбокс согласия)
- Отправка формы — POST на `https://httpbin.org/post`, модальные окна успеха и ошибки
- Пагинация — по 6 карточек на страницу через `slice()`
- Тултипы — Tippy.js, наличие товара по городам
